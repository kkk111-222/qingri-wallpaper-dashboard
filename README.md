# 晴日来信 · 在线查看版

免费的GitHub Pages静态查看页面，展示壁纸采样表格、原创作品、发布排期与本账号效果。支持手机浏览、关键词筛选、分页、CSV下载与历史记录查看。

采集和发布继续由本机程序执行，在线页面没有远程控制入口。数据是最后同步时的快照，并非实时连接小红书后台。

本仓库只保存经过字段筛选的公开查看数据及作品图片，不保存登录凭据、浏览器配置、本地文件路径或运行日志。GitHub Pages为公开网站，页面和仓库中展示的数据均可被访问者查看。

页面中的参考样本来自公开搜索页；不同平台不混排热度，空值不当作零，视频标题分析不等于完整视频理解。图片为AI辅助创作，虚构场景不对应实拍地点。

本机安装了每天19:00采样和20:00效果记录任务；运行完成后通过本机GitHub登录状态同步快照。电脑关闭或GitHub无法连接时，网站继续展示上一次成功上传的数据，页面顶部显示同步时间。
